=== Unreleased
  * Added Integration.validated_integrate: validated integration with
    rigorous lower/upper bounds. The caller supplies an enclosure oracle
    valid on any subinterval; the algorithm adaptively bisects and
    accumulates guaranteed bounds. Supports exact Rational arithmetic or
    Float arithmetic with explicit outward rounding, and returns the
    current enclosure with :budget_exhausted status when max_evaluations
    runs out before the tolerance is met.
